# poke-api

Java backend using Spring Boot to retrieve Pokemon's information.

## Stack

- Spring Boot 3
- Spring Security
- Java 25
- Caffeine (for in-memory caching)
- Jooq (for querying)
- Flyway (for db migrations)
- Resilience4j (for circuit breaking)
- Postgres

It uses `Clean Architecture` (aka `Ports and Adapters` Pattern)
